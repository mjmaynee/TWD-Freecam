TWD FREE CAMERA - The Walking Dead: The Telltale Definitive Series (Steam, PC)

A free camera, available during normal play.

INSTALL
1. Download ttarchext (Telltale TTARCH files extractor/rebuilder) by Luigi Auriemma from
   https://aluigi.altervista.org/papers.htm#ttarchext , unzip it, and copy ttarchext.exe into the
   "tools" folder of this mod. (It is not included here; install.bat also lets you paste a path.)
2. Run install.bat. It finds your Steam install (or asks for the game folder path) and builds the
   mod from your own copy of the game; no game files are included here.
3. Start the game and play normally.

UNINSTALL: run uninstall.bat. Game archives are never modified. If an update/verify of the game
files ever breaks anything, uninstalling restores the stock game.

USE
  Enter ............ free camera ON / OFF (OFF gives the game its controls back)
  W A S D .......... fly            Arrow keys ... turn / tilt
  Right mouse+drag . look around    Left mouse+drag ... pan
  Mouse wheel ...... dolly          RMB held + wheel .. fly speed
  LMB held + wheel . field of view  Escape ............ back to the main menu

NOTES
- Characters keep acting while the camera is free (scene triggers are not paused). Avoid walking
  the camera into story triggers if you do not want them to fire.
